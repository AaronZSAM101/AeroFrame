# AeroFrame brand

Adapted from the user's AeroFlux brand pack (`aeroflux-brand`, supplied 2026-11-01).

- The mark retains the shared navy compass disc, white A chevron, heading ticks, and cyan/blue route. Its lower instrument is a pair of photo prints identifying the photo library.
- Palette: ink `#0A2848`, deep `#03152A`, blue `#1E7FD8`, cyan `#2FD0EC`, pale `#A9C3D8`.
- The lowercase wordmark uses Ubuntu Bold outlines with the reference's horizontal and vertical proportions. `aero` uses navy or white ink; `frame` uses the product-line gradient.
- Glyph outlines are stored in `src/config/brandGlyphs.ts`; the source typeface is copyright 2011 Canonical Ltd., Ubuntu Font Licence 1.0. No font file or network font service is used at runtime.
- `public/favicon.svg` uses the same artwork as `aeroframe-mark.svg`; keep both in sync when changing the mark.
